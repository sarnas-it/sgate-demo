## Fallback без GitHub

```bash
scripts/demo.sh
```

Если Docker недоступен — запустить бинарники напрямую:

```bash
.tools/guardrail scan --repo . --base main --head demo/secret-leak --config guardrail.yml
.tools/deps scan --repo . --base main --head demo/critical-dependency \
  --dataset fixtures/osv-dataset \
  --pubkey-hex "$(cat fixtures/osv-dataset/pubkey.hex)" \
  --max-age 87600h --min-severity HIGH --json /tmp/sca.json
scripts/policy.py /tmp/sca.json
```

## Вопросы, которые будут задавать

| Вопрос | Ответ |
|---|---|
| Код уходит наружу? | Нет. Демо запускается с `--network none`; Deps читает офлайн-пакет, Guardrail сеть не использует. |
| А если ложное срабатывание? | Allowlist с владельцем и сроком; правило пересмотра в runbook. |
| GitLab/Jenkins? | CLI уже есть, нативные адаптеры — отдельная работа. |
| Сколько стоит? | ≈3–6 ₽ за ревью PR; цена пилота фиксируется после требований. |
| Заменит ли это SAST/DAST? | Нет. Это SCA + секреты/ПДн; SAST/DAST в сервис не входят. |
| Кто чинит? | Разработчик организации; гейт даёт план обновления и версию с исправлением. |
