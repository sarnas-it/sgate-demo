## Fallback без GitHub

Если CI недоступен, запустить локально:

```bash
DEPS_BIN=/tmp/deps GUARDRAIL_BIN=/tmp/guardrail \
  scripts/local-gate.sh origin/main demo/secret-leak
```

Ожидаемо: `Guardrail: БЛОКИРОВКА`, код возврата 1. Затем то же для
`demo/critical-dependency` — `Deps: БЛОКИРОВКА`.

## Вопросы, которые будут задавать

| Вопрос | Ответ |
|---|---|
| Код уходит наружу? | Guardrail — нет; Deps отправляет только имена/версии в OSV. Для строгого режима — офлайн-пакет баз. |
| А если ложное срабатывание? | Allowlist с владельцем и сроком; правило пересмотра в runbook. |
| GitLab/Jenkins? | CLI уже есть, нативные адаптеры — в пилоте. |
| Сколько стоит? | ≈3–6 ₽ за ревью PR; цена пилота фиксируется после требований. |
| Заменит ли это SAST/DAST? | Нет. SCA + секреты — готовы, SAST — слой пилота, DAST — отдельная оценка. |
| Кто чинит? | Разработчик заказчика; гейт даёт план обновления и версию с исправлением. |
