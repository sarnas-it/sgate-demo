# Типы ошибок SGATE по ГОСТ Р 71207-2024 (п. 8.10)

Документ генерируется командой `sgate catalog` из таблицы правил:
описание типа (6.3), причины, пример ошибочного кода, рекомендация
по исправлению и соответствие CWE.

## 6.3а. Непроверенное использование чувствительных данных

Данные из недоверенного источника (ввод пользователя, файл, сеть, переменная окружения) попадают в опасный сток без проверки: SQL-запрос, команда ОС, путь к файлу, HTTP-запрос, HTML-вывод.

**Возможные причины**

- конкатенация ввода в запрос
- использование ввода как пути
- вывод без экранирования
- запрос по URL из ввода

**Пример ошибочного кода**

```go
query := "SELECT * FROM users WHERE name = '" + r.URL.Query().Get("name") + "'"
```

**Как исправлять.** Параметризованный запрос, whitelist путей, экранирование вывода, проверка схемы и хоста URL.

**CWE:** CWE-89, CWE-78, CWE-22, CWE-79, CWE-918

**Обязателен для компилируемых языков (7.3):** да

## 6.3б. Целочисленное переполнение и смешение знаковости

Преобразование или арифметика приводят к переполнению либо к неверной интерпретации знаковых и беззнаковых значений.

**Возможные причины**

- сужение разрядности (int64 → int32)
- int ↔ uint без проверки
- переполнение при умножении/сложении

**Пример ошибочного кода**

```go
size := int(uint64(n) << 40)
```

**Как исправлять.** Проверка диапазона перед преобразованием, использование беззнаковой арифметики осознанно, safe-conversion хелперы.

**CWE:** CWE-190, CWE-191, CWE-681

**Обязателен для компилируемых языков (7.3):** да

## 6.3в. Выход за границы буфера

Чтение или запись за пределами выделенной области памяти; в Go проявляется как обращение к срезу по индексу без проверки границ.

**Возможные причины**

- индекс из внешних данных
- срез без проверки длины
- неверный расчёт размера

**Пример ошибочного кода**

```go
v := items[r.URL.Query().Get("i")]
```

**Как исправлять.** Проверка индекса и длины перед доступом, срезы с ограничением, безопасные итераторы.

**CWE:** CWE-125, CWE-787

**Обязателен для компилируемых языков (7.3):** да

## 6.3г. Некорректное использование средств защиты информации

Слабая криптография, отключённая проверка TLS, предсказуемый генератор случайных чисел, небезопасные права доступа, секреты в коде.

**Возможные причины**

- MD5/SHA1/DES/RC4
- InsecureSkipVerify
- math/rand для токенов
- права 0777/0666
- пароль в коде

**Пример ошибочного кода**

```go
h := md5.Sum([]byte(password))
```

**Как исправлять.** SHA-256/argon2, проверка сертификата, crypto/rand, права 0750/0600, секреты из хранилища.

**CWE:** CWE-327, CWE-295, CWE-338, CWE-276, CWE-798

**Обязателен для компилируемых языков (7.3):** да

## 6.3д. Ошибки работы с многопоточными примитивами

Гонки данных, неверная синхронизация, потеря сигнала при работе с потоками и примитивами синхронизации.

**Возможные причины**

- общий доступ без блокировки
- потерянное пробуждение
- захват мьютекса по значению

**Пример ошибочного кода**

```go
var mu sync.Mutex; go func() { defer mu.Unlock() }()
```

**Как исправлять.** Модель памяти языка, race detector, sync-примитивы по указателю, каналы вместо общего состояния.

**CWE:** CWE-362, CWE-833

**Обязателен для компилируемых языков (7.3):** нет, исключён перечислением д)
