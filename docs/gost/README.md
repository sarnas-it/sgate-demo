# ГОСТ Р 71207-2024 в SGATE

Комплект документов соответствия стандарту статического анализа
(ФСТЭК России, ИСП РАН). Стандарт описывает требования к анализатору и к
процессу его применения; здесь — что из этого закрыто кодом, что процессом,
а что пока нет.

| Документ | Что внутри | Кто читает |
|---|---|---|
| [`compliance-matrix.md`](compliance-matrix.md) | каждый пункт 5–10: статус и доказательство; честные пробелы (полный 7.4, CVE-проекты 10.2 в) | ИБ заказчика, тендер |
| [`error-types.md`](error-types.md) | типы ошибок 6.3 по п. 8.10: описание, причины, пример, исправление, CWE; матрица покрытия 7.3 | разработчики, ИБ |
| [`qualification-method.md`](qualification-method.md) | методика раздела 10: набор тестов, формулы 10.4/10.5, воспроизведение | ИБ, аудитор |
| [`quality-report.md`](quality-report.md) | текущее измерение: FP 5,6 %, FN 0 % на наборе из 12 ошибок | ИБ, продажи |
| [`process.md`](process.md) | процесс 5.x и 9.x: роли, цикл, разметка, SLA, месячный отчёт | владелец процесса у заказчика |

## Команды

```bash
cd core
go run ./cmd/sgate catalog -out ../docs/gost/error-types.md      # 8.10
go run ./cmd/sgate -record .sgate/runs ...                        # 8.8
go run ./cmd/sgate mark -run .sgate/runs/<id> -n 12 -category false  # 5.5, 8.6
go run ./cmd/sgate compare -cur .sgate/runs/<id> -prev -1         # 8.9
go run ./cmd/sgate quality -run .sgate/runs/<id> \
  -manifest testdata/gost-corpus/manifest.json                    # 8.4, 10.4, 10.5
```

CI: `.github/workflows/sgate-gost.yml` — тесты, прогон набора, порог 8.4,
проверка что `error-types.md` не разъехался с таблицей правил.
