# DAST auth: тестовые роли и матрица проверок

## Правила

- только тестовые учётные записи, выданные для сканирования;
- запрещены прод-аккаунты и реальные ПДн;
- секреты — в env (`DAST_TOKEN`, `DAST_COOKIE`), не в scope и не в git;
- после прогона токены отзываются.

## Матрица ролей

| Роль | Что проверяем |
|---|---|
| Аноним | закрытые страницы и API не должны отдавать данные; нет лишних методов |
| Пользователь | горизонтальный доступ: чужой объект по id, чужие заказы/документы |
| Админ | вертикальный доступ: пользователь не выполняет админ-действия |
| Гость → пользователь | регистрация, подтверждение, восстановление пароля, выход |

## Минимальные проверки

- IDOR: подмена `id` в path/query/body;
- обход авторизации: вызов API без токена;
- повышение прав: пользовательский токен на админ-ручке;
- методы: `PUT/DELETE/PATCH` на ручках, где ожидается только `GET`;
- сессия: выход, протухание токена, повторное использование cookie.

## Ограничения

- активные проверки — только на стенде или по письменному scope;
- rate limit 5 rps, kill switch;
- разрушительные методы запрещены без отдельного согласия.
